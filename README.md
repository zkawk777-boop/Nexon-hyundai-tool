# Nexon-hyundai-tool
넥슨 쿠폰 번호를 자동으로 수집해주는 도구입니다.

### 🚀 사용 방법
1. 브라우저 북마크 바에서 우클릭 -> **[페이지 추가]** 선택
2. 이름: `쿠폰 추출기` (자유롭게 입력)
3. URL: 아래 코드를 전체 복사해서 붙여넣기
