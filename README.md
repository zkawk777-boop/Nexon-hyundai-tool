# Nexon-hyundai-tool
넥슨 현대카드 쿠폰 목록을 한 번에 확인하고 PIN 번호를 복사해주는 도구예요. 

### 🚀 설치 방법 (딱 한 번만 하세요!)
1. 브라우저 북마크 바에서 마우스 오른쪽 버튼을 눌러 **[페이지 추가]**를 선택해요.
2. 이름은 `쿠폰 추출기`처럼 기억하기 쉬운 것으로 적어주세요.
3. URL 칸에 아래의 **자바스크립트 코드를 전체 복사**해서 붙여넣고 저장해요.

### 💡 사용 방법
* **자동 이동:** 다른 페이지에서 북마크를 누르면 쿠폰 목록 페이지로 바로 보내드려요.
* **클릭 한 번으로 추출:** 쿠폰 목록 페이지에서 북마크를 누르면 모든 PIN 번호를 찾아 자동으로 복사해 드려요.
